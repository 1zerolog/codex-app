# Agent Workbench

Agent Workbench is a small Codex plugin for planning complex work before execution. It borrows the useful idea behind popular multi-agent marketplaces: choose the right role for the job before doing the job.

## Included Skill

- `agent-roster` - maps a task into specialist roles, responsibilities, validation, and handoff notes.

## Use Cases

- multi-step repository changes
- release preparation
- research plus implementation
- frontend plus backend coordination
- review and remediation loops

## Notes

This plugin is intentionally lightweight. It does not spawn agents by itself; it gives Codex a repeatable planning pattern that can be used before work starts.
