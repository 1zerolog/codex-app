# Note Capture

Use this skill to turn a conversation or implementation decision into a compact Markdown note.

## Workflow

1. Identify the note purpose.
2. Capture decisions, context, and follow-up work.
3. Keep the note short and skimmable.
4. Save it only when the user asks for a file.

## Suggested Sections

- Context
- Decision
- Details
- Follow-up
