# MCP Integration Planner

MCP Integration Planner helps design tool integrations before writing code. It is shaped by popular MCP plugin patterns, but it does not bundle a server or external dependency.

## Included Skill

- `mcp-integration-plan` - plans capabilities, permissions, data flow, and validation for a new tool integration.

## Use Cases

- connecting a desktop app
- exposing repository automation
- adding an API-backed tool
- wrapping a local CLI
- planning a safe plugin boundary

## Output

The plugin produces an implementation plan, not a running integration.
