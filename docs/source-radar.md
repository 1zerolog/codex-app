This document tracks public repositories used as inspiration for Codex Labkit patterns. Codex Labkit should not vendor these repositories wholesale. Prefer small, original, Codex-native workflows with clear attribution.

## Adaptation Rule

Use public projects to identify useful categories and workflows. Write new instructions, keep examples small, and link sources instead of copying upstream content.
