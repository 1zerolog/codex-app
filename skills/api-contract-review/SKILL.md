# API Contract Review

Check endpoints, payloads, errors, pagination, auth, and backwards compatibility.

## Workflow

1. Identify the producer and consumer.
2. Review request, response, error, and auth shapes.
3. Check versioning and compatibility risks.
4. Recommend tests or fixtures.
