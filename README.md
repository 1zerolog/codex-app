# Codex App 🚀

Bu depo, Codex dâhilinde test edilebilecek basit bir Python uygulaması içerir.

## Özellikler
- `main.py`: Konsola selamlama mesajı yazdırır.
- `requirements.txt`: Bağımlılık dosyası (şu an boş).

## Kullanım
```bash
python src/main.py
```
